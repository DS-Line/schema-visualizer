# Schema Visualizer

A React/Next.js submodule for visualizing database schemas in an interactive canvas. Supports editing, highlighting, and custom node/edge rendering.


## Installation

```bash
pnpm install
```

## Start the dev server:

```bash
pnpm dev
```
